Colour — extracted from GCTU, not invented

Four navy steps are the university's literal values, taken from the inline theme CSS on site.gctu.edu.gh and from the crest PNG. The rest of the ramp is interpolated in OKLCH along hue 264 — the hue GCTU's own hero and section grounds already use.

Gold is accent only. gold-400 is the university's #ffc600 — the value its own site uses for buttons and, tellingly, for its focus outline. Only gold-700 carries text on white.

Neutrals are blue-cast at the same hue so they belong to the palette.

Status — never colour alone

Every lozenge carries a word and a glyph. These are the only statuses the API can return, so these are the only lozenges that exist.
